# 🎓 University Information System (Java Swing + MySQL)

An advanced, object-oriented University Information System built with **Java Swing** and **MySQL**. This project simulates a real-world university's academic and administrative processes including **student enrollment**, **course management**, **staff assignments**, and **grade tracking** — all through an intuitive GUI.

---

## 🧠 Features

- 🔐 **Role-based Login System** (Admin, Lecturer, Assistant Lecturer, Student, Management)
- 🧑‍🎓 Student Enrollment & Degree Assignment
- 📚 Course & Module Management
- 🧑‍🏫 Lecturer & Assistant Lecturer Management
- 🏫 Academic Department & Program Setup
- 🗂️ Section Management with Lecturer Assignments
- 📊 Grade Management
- 📅 Semester and Academic Year Tracking
- 👩‍💼 University Staff (Management Roles) Integration
- 🗃️ MySQL Relational Database Backend

---

## 📂 GUI Interfaces

- `AdminDashboard`, `LecturerDashboard`, `StudentDashboard`, `ManagementDashboard`
- Add/Manage forms for: Students, Lecturers, Assistant Lecturers, Management Staff, Courses, Grades
- Module & Section assignment interfaces

---

## 🏗️ Technologies Used

- **Java Swing (JFrame, NetBeans Form Builder)**
- **MySQL Database**
- JDBC for Database Connectivity
- Object-Oriented Design Principles

---

## 💾 Database Setup

1. Import the `DataBase.sql` file into your MySQL Server.
2. Create a database named `UniversityDB`.
3. Run the SQL script to create all required tables and constraints.
4. Update your Java JDBC connection strings with appropriate database credentials.

---

## 🚀 Getting Started

1. Clone this repository:
    ```bash
    git clone https://github.com/your-username/university-information-system.git
    ```
2. Open the project in **NetBeans** (recommended).
3. Make sure you have the **MySQL JDBC driver** added to your project libraries.
4. Run the application from `Main.java`.
